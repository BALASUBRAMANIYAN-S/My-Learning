# My Learning

A personal learning journal. I keep my practice code, notes and roadmaps here, organised by subject.

## Contents

### `JAVASCRIPT/`
Practice files for learning JavaScript step by step.

| Folder | Topics |
|---|---|
| `BASICS/` | Block scope, conditional statements, functions (normal, arrow, callback, expression), loops, operators |
| `INTERMIDIATE/` | Arrays (`map`, `filter`, `reduce`, `forEach`), destructuring, `Math`, objects and classes, optional chaining, string functions |
| `Others/` | Asynchronous code (callbacks, promises, `async/await`), data types and type conversion, ES6, template literals |

### `DOCUMENTS/`
- `AI Development/`: notes on LLM fundamentals, RAG, fine-tuning and pre-training
- `DSA/`: data structures and algorithms roadmaps (`Roadmap.txt`, `Roadmap_extended_python.txt`)

## How to use

Each JavaScript file runs on its own with Node.js:

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/My-Learning.git
cd My-Learning/JAVASCRIPT/BASICS/Loops
node ForLoop.js
```
