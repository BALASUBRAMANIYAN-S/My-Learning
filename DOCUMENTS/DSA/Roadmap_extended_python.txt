======================================================================
               🐍 PYTHON-SPECIFIC DSA TOOLKIT 🐍
======================================================================
Unlike other languages, Python has built-in modules that make DSA 
much easier. DO NOT reinvent the wheel. Learn these standard libraries:

[ ] 1. COLLECTIONS MODULE (Crucial!)
    - collections.deque: MUST use this for Queues and BFS. 
      (Using a standard list `queue.pop(0)` is O(n) time, 
      `deque.popleft()` is O(1) time).
    - collections.Counter: Instantly creates frequency hash maps.
      Example: Counter("hello") -> {'h':1, 'e':1, 'l':2, 'o':1}
    - collections.defaultdict: Great for Graph Adjacency Lists to 
      avoid KeyError.

[ ] 2. HEAPQ MODULE (For Heaps/Priority Queues)
    - Python only has a built-in Min-Heap: `import heapq`
    - To make a Max-Heap, multiply all values by -1 before pushing, 
      and multiply by -1 again when popping.

[ ] 3. FUNCTOOLS (Cheat code for Dynamic Programming)
    - @cache or @lru_cache(None)
    - If you write a recursive function for DP, just put @cache 
      above it, and Python does the Memoization automatically!

[ ] 4. BUILT-IN FUNCTIONS
    - divmod(a, b): Returns quotient and remainder at once.
    - math.inf / -math.inf: Use this to initialize max/min variables.
    - list.sort(key=lambda x: ...): Learn how to use lambda functions 
      to sort arrays of intervals, strings, or objects.

[ ] 5. SLICING & REVERSING
    - Reversing an array/string: `arr[::-1]`
    - Getting a substring: `string[start:end]`

[ ] 6. RECURSION LIMIT
    - Python has a default recursion limit of 1000. For deep DFS 
      graphs, you might need:
      `import sys`
      `sys.setrecursionlimit(2000)`
